# 🚀 SQL Foundations: Interactive Obsidian Vault & Visual Roadmap

An intuitive, visual-first starter vault designed to help you master SQL fundamentals directly inside Obsidian without technical fluff or academic jargon.

---

## 🌟 What's Included

- 🗺️ **Interactive Canvas Roadmap (`SQL Roadmap.canvas`):** Follow a visual pathway step-by-step.
- 🌙 **Dark-Mode Optimized:** Native Markdown tables styled cleanly for Obsidian dark themes.
- 💻 **Copy-Paste Code Blocks:** Ready-to-run SQL examples using an independent `SciFi_Movies` dataset.
- 🔭 **Zero-Jargon Explanations:**
  - `01_BASIC_QUERIES`: `SELECT`, `FROM`
  - `02_QUERIES_WITH_CONSTRAINTS_PART_1`: `WHERE`, `AND`, `OR`, `BETWEEN`, `IN`
  - `02_QUERIES_WITH_CONSTRAINTS_PART_2`: `LIKE`, `%`, `_`
  - `03_FILTERING_AND_SORTING`: `DISTINCT`, `ORDER BY`, `LIMIT`, `OFFSET`

---

## 📥 How to Use

1. Click the green **[Code]** button at the top right of this page and select **[Download ZIP]**.
2. Extract the `.zip` folder on your computer.
3. Open Obsidian, click **"Open folder as vault"**, and select the extracted folder.
4. Open `00_START_HERE.md` or `SQL Roadmap.canvas` to start learning!
